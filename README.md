# 🌸 Cherry Blossom Chill Theme

> A calm, elegant and comfortable theme for Visual Studio Code, inspired by the beauty of cherry blossoms.

**Cherry Blossom Chill Theme** was created to bring a softer and more pleasant atmosphere to your coding environment.

Inspired by cherry blossoms and carefully selected tones, the theme combines **soft colors, readability and a relaxing aesthetic** designed for long coding sessions.

---

## ✨ Features

* 🌸 Cherry blossom inspired color palette
* 🎨 Carefully balanced editor colors
* 👀 Designed with readability in mind
* 💻 Comfortable for long coding sessions
* 🌙 Clean and minimal visual identity
* ⚡ Lightweight and easy to use

---

## Available Themes

Cherry Blossom Chill is now available in two variations:

### Cherry Blossom Chill Light
The original theme, featuring a soft and elegant color palette inspired by cherry blossoms.

### Cherry Blossom Chill Dark
A darker alternative, preserving the extension's signature cherry blossom aesthetic with deeper tones and refined contrasts.

Choose the variation that best suits your coding environment and personal preference!

---

## 📦 Installation

You can install **Cherry Blossom Chill Theme** directly from the Visual Studio Code Marketplace.

1. Open **Visual Studio Code**
2. Open the **Extensions** panel
3. Search for **Cherry Blossom Chill Theme**
4. Click **Install**
5. Open the Command Palette with `⌘ + Shift + P` / `Ctrl + Shift + P`
6. Select **Preferences: Color Theme**
7. Choose **Cherry Blossom Chill Theme**

## 🎨 The Idea Behind the Theme

The goal of this project is simple:

> **Create a programming environment that is calm, comfortable, inspiring, and unique.**

Instead of focusing only on functionality, Cherry Blossom Chill Theme explores how colors and visual balance can influence the experience of writing code.
